ASL alphabet, 26 letters

Sign a letter. See it typed.

Hold an ASL letter in front of your webcam and watch it appear as text. Hand position is read by MediaPipe, then classified by a Random Forest trained on the public ASL Alphabet dataset.

Start translating How it works

01

Twenty one hand landmarks

MediaPipe locates 21 joints per hand. Each has an x, y and z coordinate, giving 63 numbers that describe the shape of your hand.

02

Distance invariant features

Landmarks are centred on the wrist and divided by hand size, so a letter reads the same whether your hand is near the camera or far from it.

03

Smoothed over time

A letter is committed only once a majority of recent frames agree, so one noisy frame never types the wrong character.

Measured performance

Numbers from the held out test split. Live webcam accuracy is lower, so both are reported rather than only the flattering one.

97.9%

Offline test accuracy

Held out split of the public image dataset, 1,143 samples. This figure is not a webcam measurement.

0.97

Macro F1

Every letter weighted equally, so the score is not flattered by the better represented classes.

26

Classes

The static A to Z alphabet. Motion based signs are treated as fixed poses here.

Known limitation. M and N are often confused on a webcam. The thumb position that separates them sits hidden behind the fingers in both signs, so the landmark model cannot see it reliably.
